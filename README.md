# HighSpeedVPN

> Современный VPN-сервис с управлением через Telegram-бота.

---

## О проекте

**HighSpeedVPN** — это сервис для автоматизированной выдачи VPN-доступа с использованием **Telegram-бота**, собственного **Backend API** и протокола **AmneziaWG2**.

Проект ориентирован на простоту использования для конечных пользователей и удобство сопровождения для администратора.

На первом этапе управление VPN осуществляется через **amnezia-api**, с возможностью дальнейшего перехода на собственный сервис управления VPN.

---

## Основные возможности

* Регистрация пользователей через Telegram
* Покупка и продление подписок
* Автоматическая выдача VPN-конфигураций
* Поддержка протокола AmneziaWG2
* Управление устройствами
* Поддержка нескольких VPN-серверов (в будущем)
* Административная панель (в разработке)

## Используемые технологии

| Backend         | Fastify                |

| VPN API         | amnezia-api            |
| Контейнеризация | Docker, Docker Compose |
