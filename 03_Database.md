# HighSpeedVPN — Database Structure

**Версия документа:** 1.0
**Дата создания:** 04.08.2026
**Статус:** В разработке

---

# 1. Назначение документа

Документ описывает структуру базы данных проекта HighSpeedVPN, основные сущности, их поля и взаимосвязи.

База данных предназначена для хранения информации о пользователях, подписках, VPN-серверах, платежах и других объектах системы.

---

# 2. Используемая СУБД

В качестве основной системы управления базами данных используется:

* PostgreSQL

---

# 3. Основные сущности

В системе используются следующие сущности:

* Users
* Subscriptions
* Tariffs
* Servers
* VPN Clients
* Devices
* Payments
* Promo Codes
* Logs

# 14. Основные принципы

При проектировании базы данных используются следующие принципы:

* использование UUID в качестве первичных ключей;
* хранение дат в UTC;
* использование внешних ключей для обеспечения целостности данных;
* отсутствие дублирования информации;
* поддержка масштабирования на несколько VPN-серверов;
* возможность безопасного расширения структуры без нарушения совместимости.
