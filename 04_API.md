# HighSpeedVPN — Backend API Specification

**Версия документа:** 1.0
**Дата создания:** 04.08.2026
**Статус:** В разработке

---

# 1. Назначение документа

Документ описывает REST API Backend-сервиса HighSpeedVPN.

Backend API является единой точкой входа для Telegram-бота, панели администратора и внутренних сервисов системы.

---

# 2. Общая информация

## Базовый URL

```text
https://api.highspeedvpn.example/api/v1
```

> Адрес приведен в качестве примера и будет изменен при развертывании.

---

## Формат обмена

Все запросы и ответы используют формат JSON.

---

## Коды ответа

| Код | Описание                  |
| --- | ------------------------- |
| 200 | Успешно                   |
| 201 | Объект создан             |
| 204 | Успешно, без содержимого  |
| 400 | Некорректный запрос       |
| 401 | Не авторизован            |
| 403 | Доступ запрещен           |
| 404 | Не найдено                |
| 409 | Конфликт данных           |
| 500 | Внутренняя ошибка сервера |

---

# 3. API пользователей

## Создание пользователя

**POST**

```text
/users
```

Создает пользователя при первом обращении через Telegram.

---

## Получение пользователя

**GET**

```text
/users/{id}
```

Возвращает информацию о пользователе.

---

## Получение пользователя по Telegram ID

**GET**

```text
/users/telegram/{telegramId}
```

Используется Telegram-ботом.

---

# 4. API тарифов

## Получить список тарифов

**GET**

```text
/tariffs
```

Возвращает список доступных тарифов.

---

## Получить тариф

**GET**

```text
/tariffs/{id}
```

---

## Создать тариф

**POST**

```text
/tariffs
```

Доступно только администратору.

---

## Изменить тариф

**PUT**

```text
/tariffs/{id}
```

---

## Удалить тариф

**DELETE**

```text
/tariffs/{id}
```

---
