# HighSpeedVPN — RoadMap

**Версия документа:** 1.0
**Дата создания:** 05.08.2026
**Статус:** В разработке

---

# 1. Назначение документа

Документ определяет этапы разработки проекта HighSpeedVPN, приоритеты реализации функциональности и направления дальнейшего развития.

RoadMap является ориентиром для разработки и может корректироваться по мере появления новых требований.

---

# 2. Цели проекта

Основные цели проекта:

* создать стабильный VPN-сервис;
* предоставить удобный Telegram-бот для пользователей;
* автоматизировать управление подписками;
* минимизировать ручное администрирование;
* обеспечить возможность масштабирования проекта.

---

# 3. Принципы разработки

Разработка ведется по следующим принципам:

* сначала реализуется минимально жизнеспособный продукт (MVP);
* каждая новая функция должна быть завершенной и протестированной;
* изменения не должны нарушать работу существующего функционала;
* архитектура должна оставаться модульной и расширяемой.

---

# 4. Этап 1 — MVP

**Цель:** получить полностью работоспособную первую версию сервиса.

### Backend

* Реализовать REST API.
* Подключить PostgreSQL.
* Реализовать авторизацию между компонентами.
* Настроить логирование.

### Telegram Bot

* Регистрация пользователя.
* Главное меню.
* Просмотр профиля.
* Просмотр тарифов.
* Покупка подписки.
* Получение конфигурации.
* Инструкции по подключению.
* Поддержка.

### VPN

* Интеграция с `amnezia-api`.
* Создание VPN-клиента.
* Удаление VPN-клиента.
* Выдача конфигурации AmneziaWG2.

### База данных

* Пользователи.
* Подписки.
* Тарифы.
* Серверы.
* Устройства.
* История платежей.

### Инфраструктура

* Docker Compose.
* Nginx.
* PostgreSQL.
* Backend API.
* Telegram-бот.
* `amnezia-api`.

**Критерий завершения этапа:**

Пользователь может пройти путь от команды `/start` до получения рабочей конфигурации AmneziaWG2 без участия администратора.

---

# 5. Этап 2 — Улучшение пользовательского опыта

**Цель:** сделать сервис удобнее для пользователей.

Планируемые задачи:

* продление подписки;
* управление устройствами;
* автоматические уведомления;
* история платежей;
* улучшение инструкций;
* поддержка нескольких языков;
* FAQ.

**Критерий завершения этапа:**

Все основные пользовательские действия выполняются через Telegram-бот без необходимости обращаться в поддержку.

---

# 6. Этап 3 — Масштабирование

**Цель:** обеспечить работу с несколькими VPN-серверами.

Планируемые задачи:

* поддержка нескольких серверов;
* автоматический выбор сервера;
* балансировка нагрузки;
* мониторинг состояния серверов;
* отображение загрузки серверов;
* резервные серверы.

**Критерий завершения этапа:**

Пользователи автоматически распределяются между доступными VPN-серверами.

---

# 7. Этап 4 — Развитие платформы

**Цель:** расширить возможности сервиса.

Планируемые задачи:

* промокоды;
* реферальная программа;
* расширенная статистика;
* журнал действий пользователей;
* административная панель;
* экспорт отчетов.

**Критерий завершения этапа:**

Администратор может управлять сервисом через веб-интерфейс без необходимости использовать консоль.

---

# 8. Этап 5 — Собственный сервис управления VPN

**Цель:** отказаться от зависимости от стороннего `amnezia-api`.

Планируемые задачи:

* разработка собственного VPN Backend;
* реализация API управления VPN;
* генерация конфигураций;
* управление клиентами;
* сбор статистики;
* централизованное управление несколькими VPN-серверами.

**Критерий завершения этапа:**

Backend полностью управляет VPN-инфраструктурой без использования стороннего `amnezia-api`.

---

# 9. Этап 6 — Долгосрочное развитие

Возможные направления развития:

* веб-кабинет пользователя;
* мобильное приложение;
* дополнительные способы оплаты;
* партнерская программа;
* публичный API;
* поддержка дополнительных VPN-протоколов;
* интеграция с внешними системами мониторинга.

| Средний   | Улучшения пользовательского опыта и автоматизация |

---

# 11. Основные риски

При разработке необходимо учитывать:

* зависимость от стороннего `amnezia-api`;
* изменения API Telegram;
* изменения в платежных системах;
* увеличение нагрузки при росте количества пользователей;
* необходимость миграции на собственный VPN Backend.

Для каждого риска должны быть предусмотрены меры по минимизации последствий.

---

# 12. Критерии успешности проекта

Проект считается успешно реализованным, если:

* пользователь может самостоятельно зарегистрироваться;
* оформление и продление подписки выполняются автоматически;
* конфигурация AmneziaWG2 выдается без участия администратора;
* система поддерживает подключение нескольких VPN-серверов;
* инфраструктура готова к дальнейшему масштабированию.

---

# 13. Итог

Разработка HighSpeedVPN ведется поэтапно: сначала создается минимально жизнеспособный продукт с использованием готового `amnezia-api`, затем постепенно расширяется функциональность и инфраструктура. Конечной целью является создание полностью автономной платформы с собственным сервисом управления VPN, поддержкой масштабирования и удобным пользовательским интерфейсом.
