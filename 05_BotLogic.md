# HighSpeedVPN — Telegram Bot Logic

**Версия документа:** 1.0
**Дата создания:** 04.08.2026
**Статус:** В разработке

---

# 1. Назначение документа

Документ описывает логику работы Telegram-бота HighSpeedVPN, пользовательские сценарии, структуру меню и последовательность взаимодействия пользователя с системой.

---

# 2. Основные задачи бота

Telegram-бот является основным пользовательским интерфейсом системы и должен обеспечивать:

* регистрацию пользователя;
* управление подписками;
* покупку VPN;
* получение конфигурации WireGuard;
* управление устройствами;
* отображение информации о профиле;
* связь с технической поддержкой.

---

# 3. Главное меню

После авторизации пользователю отображается главное меню.

---

# 6. Раздел "Моя подписка"

Пользователь может посмотреть:

* текущий тариф;
* дату окончания;
* оставшееся время;
* выбранный сервер;
* количество устройств;
* статус подписки.

Доступные действия:

* Продлить подписку
* Скачать конфигурацию
* Получить QR-код
* Открыть инструкцию

---

# 7. Раздел "Мои устройства"

Пользователь может:

* посмотреть список устройств;
* добавить устройство;
* удалить устройство;
* переименовать устройство;
* скачать конфигурацию для конкретного устройства.

---

# 8. Раздел "Серверы"

Отображается список доступных серверов.

Для каждого сервера отображается:

* название;
* страна;
* город;
* текущая загрузка;
* статус.

Если смена сервера разрешена тарифом, пользователь может выбрать другой сервер.

---

# 9. Раздел "Профиль"

Отображается информация:

* Telegram ID;
* Username;
* дата регистрации;
* количество подписок;
* активный тариф.

---

# 10. Раздел "Инструкция"

Пользователь выбирает платформу:

```text
Android

iPhone

Windows

macOS

Linux
```

После выбора отправляется:

* инструкция;
* ссылка на WireGuard;
* рекомендации по подключению.

---

# 11. Раздел "Поддержка"

Возможности:

* написать в поддержку;
* открыть FAQ;
* посмотреть ответы на популярные вопросы.

---

# 12. Раздел "Настройки"

Пользователь может:

* изменить язык;
* включить или отключить уведомления;
* изменить часовой пояс (при необходимости).

---

# 13. Уведомления

Бот автоматически отправляет уведомления:

* подписка успешно оформлена;
* платеж подтвержден;
* VPN-конфигурация готова;
* до окончания подписки осталось 7 дней;
* до окончания подписки остался 1 день;
* подписка истекла;
* подписка успешно продлена.

---

# 14. Обработка ошибок

При возникновении ошибок бот отображает понятные сообщения.

Примеры:

* пользователь не найден;
* подписка отсутствует;
* подписка истекла;
* сервер временно недоступен;
* платеж не подтвержден;
* ошибка создания VPN-конфигурации.

Во всех случаях пользователю предлагается повторить действие или обратиться в поддержку.

# 17. Основные принципы

При разработке Telegram-бота необходимо придерживаться следующих принципов:

* минимальное количество действий для пользователя;
* понятная навигация;
* единый стиль оформления;
* отсутствие сложных команд;
* использование кнопок вместо текстового ввода там, где это возможно;
* информативные сообщения об ошибках;
* вся бизнес-логика выполняется Backend API.

# 20. Итог

Telegram-бот является основным интерфейсом взаимодействия пользователя с сервисом HighSpeedVPN. Он должен обеспечивать максимально простой путь от регистрации до получения рабочего VPN-доступа, скрывая технические детали и предоставляя пользователю удобный и понятный интерфейс.
